# 🛡️ ESP32 WiFi Scanner & Network Tool

أداة متقدمة لفحص شبكات WiFi باستخدام ESP32 مع واجهة ويب تفاعلية.

## ⚠️ تحذير قانوني مهم جداً

**هذه الأداة للأغراض التعليمية والاختبارات الأمنية المصرح بها فقط!**

- فحص شبكتك الخاصة
- اختبار الاختراق المصرح به (Penetration Testing)
- مسابقات CTF (Capture The Flag)
- البحث الأمني والتعليم
- الأغراض التعليمية في بيئة آمنة

- الوصول غير المصرح به إلى الشبكات
- التجسس على شبكات الآخرين
- أي استخدام ضار أو غير قانوني

**المسؤولية القانونية:** أنت وحدك المسؤول عن استخدام هذه الأداة. تأكد من الامتثال للقوانين المحلية.

## 🔧 متطلبات التشغيل

### الأجهزة المطلوبة
- لوحة ESP32 (أي نوع)
- كابل USB للبرمجة

### البرامج المطلوبة

#### الخيار 1: Arduino IDE (سهل للمبتدئين)
1. تحميل Arduino IDE من [الموقع الرسمي](https://www.arduino.cc/en/software)
2. إضافة دعم ESP32:
   - افتح `File` > `Preferences`
   - أضف هذا الرابط في `Additional Boards Manager URLs`:
     ```
     https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
     ```
   - افتح `Tools` > `Board` > `Boards Manager`
   - ابحث عن "ESP32" وقم بتثبيته

#### الخيار 2: PlatformIO (موصى به للمحترفين)
```bash
# تثبيت PlatformIO
pip install platformio

# أو استخدم VSCode مع إضافة PlatformIO
```

## 📥 التثبيت والتشغيل

### باستخدام Arduino IDE

1. **فتح المشروع:**
   - افتح ملف `esp32_wifi_scanner.ino`

2. **إعداد اللوحة:**
   - `Tools` > `Board` > اختر لوحة ESP32 الخاصة بك
   - `Tools` > `Port` > اختر المنفذ المناسب

3. **تخصيص الإعدادات (اختياري):**
   ```cpp
   // في بداية الكود، يمكنك تغيير:
   const char* ap_ssid = "ESP32-WiFi-Scanner";     // اسم نقطة الوصول
   const char* ap_password = "12345678";            // كلمة المرور (8 أحرف على الأقل)
   ```

4. **رفع الكود:**
   - اضغط على زر `Upload` (السهم)
   - انتظر حتى يكتمل الرفع

5. **فتح Serial Monitor:**
   - `Tools` > `Serial Monitor`
   - اضبط السرعة على `115200 baud`

### باستخدام PlatformIO

1. **إنشاء المشروع:**
   ```bash
   pio project init --board esp32dev
   ```

2. **نسخ الكود:**
   - انسخ محتوى `esp32_wifi_scanner.ino` إلى `src/main.cpp`

3. **رفع الكود:**
   ```bash
   pio run --target upload
   pio device monitor
   ```

## 🔒 فهم أنواع التشفير

### أنواع التشفير حسب قوة الأمان:

| التشفير | الأمان | الوصف | التوصية |
|---------|--------|--------|----------|
| **Open** | ⚠️ Very Weak | لا يوجد تشفير، أي شخص يمكنه الاتصال والتجسس | ❌ لا تستخدمه أبداً |
| **WEP** | 🔴 Weak | تشفير قديم جداً، يمكن كسره في دقائق | ❌ عفا عليه الزمن |
| **WPA** | 🟡 Moderate | أفضل من WEP لكن به ثغرات معروفة | ⚠️ استبدله بـ WPA2/3 |
| **WPA2** | 🟢 Strong | معيار قوي وآمن، مناسب للاستخدام | ✅ جيد للاستخدام |
| **WPA3** | 🟢 Very Strong | أحدث وأقوى معيار تشفير | ✅ الأفضل والموصى به |

### قراءة قوة الإشارة (RSSI):

| القيمة (dBm) | القوة | الوصف |
|--------------|-------|--------|
| -30 إلى -50 | ممتاز | إشارة قوية جداً، مسافة قريبة |
| -50 إلى -60 | جيد | إشارة جيدة، سرعة عالية |
| -60 إلى -70 | متوسط | إشارة مقبولة، قد تتأثر السرعة |
| -70 إلى -80 | ضعيف | إشارة ضعيفة، اتصال غير مستقر |
| -80 وأقل | ضعيف جداً | إشارة ضعيفة جداً، صعوبة في الاتصال |

## 🎓 معلومات تعليمية عن أمان الشبكات

### كيف يتم اختراق الشبكات؟

#### 1. الشبكات المفتوحة (Open)
- **المشكلة:** لا يوجد أي تشفير
- **الخطر:** يمكن لأي شخص رؤية جميع البيانات المرسلة
- **الحل:** استخدم VPN أو لا تستخدم هذه الشبكات للمعلومات الحساسة

#### 2. تشفير WEP
- **المشكلة:** خوارزمية تشفير ضعيفة ومكسورة
- **الخطر:** يمكن كسرها في 5-10 دقائق باستخدام أدوات مثل Aircrack-ng
- **الحل:** ترقية الراوتر أو تحديث التشفير إلى WPA2/WPA3

#### 3. WPS (Wi-Fi Protected Setup)
- **المشكلة:** ثغرة في تصميم النظام
- **الخطر:** يمكن تخمين PIN في ساعات قليلة
- **الحل:** تعطيل WPS من إعدادات الراوتر

#### 4. كلمات المرور الضعيفة
- **المشكلة:** كلمات مرور سهلة التخمين
- **الخطر:** هجمات القاموس (Dictionary Attack) أو Brute Force
- **الحل:** استخدم كلمات مرور قوية (12+ حرف، أرقام، رموز)

### نصائح لحماية شبكتك:

#### 1. التشفير ✅
- استخدم WPA2 أو WPA3 فقط
- عطل WEP و WPA تماماً
- عطل WPS

#### 2. كلمة المرور 🔐
- استخدم على الأقل 12 حرف
- امزج بين حروف كبيرة وصغيرة وأرقام ورموز
- لا تستخدم كلمات قاموسية أو معلومات شخصية
- مثال جيد: `MyW!f1_2024@SecUre#`

#### 3. إعدادات الراوتر 🔧
- غير اسم المستخدم وكلمة المرور الافتراضية للراوتر
- أخفِ اسم الشبكة (SSID) إذا أمكن
- حدث firmware الراوتر بانتظام
- عطل الإدارة عن بُعد (Remote Management)

#### 4. مراقبة الشبكة 👀
- راقب الأجهزة المتصلة بانتظام
- استخدم MAC Address Filtering
- قم بتقسيم الشبكة (Guest Network للضيوف)

## 📡 فهم بيانات الشبكة

### SSID (Service Set Identifier)
- اسم الشبكة الذي تراه عند البحث عن WiFi
- يمكن إخفاءه (Hidden Network)

### BSSID (Basic Service Set Identifier)
- عنوان MAC الفريد للراوتر/نقطة الوصول
- مثال: `AA:BB:CC:DD:EE:FF`
- لا يمكن تغييره بسهولة

### RSSI (Received Signal Strength Indicator)
- قوة الإشارة بالديسيبل ميلي واط (dBm)
- القيم سالبة: كلما كانت أقرب للصفر، كانت الإشارة أقوى

### Channel (القناة)
- قنوات 2.4 GHz: 1-14 (معظم الدول تستخدم 1-13)
- قنوات 5 GHz: 36, 40, 44, 48, 149, 153, 157, 161
- القنوات المتداخلة تسبب التداخل (Interference)

## 🔍 استكشاف الأخطاء

### المشكلة: لا يمكن رؤية نقطة الوصول

**الحلول:**
1. تأكد من رفع الكود بنجاح
2. افتح Serial Monitor وتحقق من الرسائل
3. أعد تشغيل ESP32
4. تأكد من أن كلمة المرور 8 أحرف أو أكثر

### المشكلة: لا يمكن الاتصال بالواجهة

**الحلول:**
1. تأكد من الاتصال بشبكة WiFi الخاصة بالـ ESP32
2. استخدم العنوان الصحيح: `http://192.168.4.1`
3. جرب متصفح مختلف
4. امسح الكاش (Cache)

### المشكلة: لا يظهر أي شبكات

**الحلول:**
1. تأكد من وجود شبكات WiFi نشطة في المنطقة
2. أعد تشغيل ESP32
3. اضغط على زر "مسح الشبكات" يدوياً

### المشكلة: ESP32 يتوقف أو يعيد التشغيل

**الحلول:**
1. تأكد من كابل USB جيد وإمداد طاقة كافي
2. قد يكون عدد الشبكات كبير جداً - قلل مدة المسح
3. أضف تأخير أكبر بين المسحات
